## token 怎么算：价格与计价单位

Navicat Monitor 不按主机数收，也不按数据量收，只认 token。官方给的换算规则是这样的：

- 1 台 MySQL 服务器 = 1 token
- 1 台 MariaDB 服务器 = 1 token
- 1 台 PostgreSQL 服务器 = 1 token
- 1 台 SQL Server = 1 token
- 4 个 Azure 数据库 = 1 token

主从两台机器就是两个 token，读写分离的架构按实际机器数往上加。上云的部分只有 Azure 数据库有 4 合 1 的优惠，其他云厂商的托管数据库还是按一台算。

永久授权是 US$1,299 一个 token，官方标注的是经销商价口径，含 1 年软件维护，也就是这一年内能拿到版本升级和技术支持。第二年的维护要单独买，价格同样要选了周期才显示。

把数量折扣算进去，成本曲线是这样的。5 个 token 原价 6,495 美元，8 折后 5,196 美元，平均每台 1,039 美元。10 个 token 原价 12,990 美元，7 折后 9,093 美元，平均每台 909 美元。二十台以上每台还能再降。

有个数字值得单独拎出来：5 个 token 打完 8 折是 5,196 美元，正好等于 4 个 token 的原价（4 × 1,299 = 5,196）。第 5 台等于白送。这是整个价格表里最划算的一个点，前提是你一年内真的会用上第 5 台库。

订阅这边，同一个 token 按月付或者按年付，累计几年下来总支出会追上甚至超过 1,299 美元的永久价，具体几年取决于页面上的月费和年费，拿计算器一除就知道。订阅的优势是把支出摊薄，不是更便宜。

## 几个容易踩的坑

成本随库数量线性上升，这是 Navicat Monitor 最实在的缺点。它没有“按团队打包”或者“按机器数封顶”的档位，库从 5 台涨到 50 台，token 就得从 5 个买到 50 个，只能靠数量折扣把单价压下来，而且折扣只给永久授权，订阅用户没有任何议价空间。实例规模大的团队，第二年的预算要提前跟财务说清楚。

一个订单只发一个 key，key 只能激活在装了 Navicat Monitor 的一台机器上，激活之后剩下的 token 不能转到另一台机器。这意味着买 10 个 token 和买 1 个 token，收到的东西都是一个 key。别在测试机上随手激活，正式环境定下来再动手。

维护计划里包含 key reset 申请，机器重装或者迁移之前先确认维护还在有效期内。永久授权只含 1 年维护，第二年不续费，软件照常跑，但拿不到新版本，也申请不了 key reset。

荔枝商城的 Navicat 系列商品不是自动发货，下单后通常要 1 到 2 个工作日人工处理，赶上线节点的提前几天下单。单个账号有限购，批量采购需要联系客服单独处理。

授权码激活后一般不支持退换，token 数量在下单前数清楚，尤其是主从和多环境这几台容易被漏掉。
